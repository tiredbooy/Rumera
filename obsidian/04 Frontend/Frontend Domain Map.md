# Frontend Domain Map

Ownership: business capability lives in `features/<domain>/`.

Examples:

- `catalog/*` → [[Catalogue]] · [[Storefront Commerce FE]]
- `cart` `checkout` → [[Cart and Checkout]]
- `inventory` + `admin/inventory` → [[Inventory FE]]
- `account/*` + wallet/loyalty → [[Account FE]]
- `recipes` → [[Recipes and Journal]]
- `storefront/search` → [[Search FE]]

Never rebuild a catch-all `lib/catalog`.

Related: [[Business Domains MOC]] · [[Platform Layer]] · [[Backend Domain Map]]
