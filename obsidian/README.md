# Rumera — Project Brain (Obsidian vault)

Linked knowledge graph of the Rumera monorepo.

## Open

1. Install [Obsidian](https://obsidian.md).
2. **Open folder as vault** → `Rumera/obsidian` (not the monorepo root).
3. Open **`Brain/Project Brain`** first.
4. `Ctrl/Cmd + G` → Graph → use **Local graph** on Project Brain to see every folder ray.

## Graph center: `Brain/`

| Note | Role |
|------|------|
| [[Project Brain]] | **Center** of the vault |
| [[Connect 00 Meta]] … [[Connect 13 Surfaces]] | One connector per folder; each lists that folder’s notes and links back to Project Brain |

Every content note also carries:

```text
**Brain:** [[Project Brain]] · [[Connect NN …]]
```

So the Graph stays one connected star, not islands.

## Required reading before editing

| Note | Purpose |

When you add a note: put it in `01`–`13` folders, then **add a link on the matching Connect note** under `Brain/`.

## Other folders

`00 Meta` … `13 Surfaces` hold the actual knowledge (domains, ADRs, playbooks, …).  
Long manuals stay in `docs/` and `apps/*/docs/` — see [[Documentation Bridge]].
